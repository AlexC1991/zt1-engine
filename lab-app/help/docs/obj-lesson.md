# Jade Shellback: OBJ poses into game frames

Source: source-assets/jade-shellback-01.obj, source-assets/jade-shellback-02.obj and source-assets/jade-shellback.mtl

Create a zoo animal based on Plains Zebra. Draw walk → Blank → Import external art. Select both numbered OBJ files and their MTL together. Use Y-up, front +Z, height 32 and 200 ms per supplied pose. The two meshes supply the leg poses; the importer does not rig or invent a walk.

Save compiles the game art. For this prototype, Link other poses reuses that art for the other adult states; wait for it to finish. Add its own food, habitat and group values in Needs and the Inspector. Pictures → Use an animation frame makes its icon, list picture and plaque.
