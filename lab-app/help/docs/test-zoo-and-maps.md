# Build a test zoo and a custom map

## Start small and pause

In **Test Zoo**, choose an existing freeform map, a flattened map, or **New map** with a blank size. Pause while building. A blank map begins in **Edit the map**, allowing you to arrange the boundary and entrance. Finish and save custom asset edits before laying out a map that uses them.

## Draw the zoo boundary

Use the Zoo Fence for a closed boundary and place a zoo entrance where guests should enter. Connect its entrance to a path. Switch **Edit the map** off to check which ground counts as inside the zoo. The Terrain view and exhibit overlay help spot gaps. A decorative gate is not automatically the zoo entrance.

## Build a land exhibit

Close the enclosure, add a gate and connect its outside to the staff path. Paint suitable ground and add water, plants, rocks, shelter or enrichment according to the animal's Needs. Put the right carer outside with access to the gate. A low fence that contains one species may not contain a jumping dinosaur.

## Build a marine tank

Make a complete tank-wall enclosure. Check the actual water depth, not just wall height. Add a reachable filter outside, appropriate water conditions, underwater objects and a marine specialist. Check allowed tank placement and rejected land or shallow-water placement. Observe natural surface and submerged swimming rather than forcing an animation preview.

## Test a service object

Connect buildings and furniture to accessible paths and check their orientation. Hire the relevant staff. Run normal visitors and service cycles: a kiosk should serve a guest; a bench should be usable; a bin should accumulate and be emptied; a filter should clean, wear and be serviced. A placement preview proves only that the art loads.

## Save and reopen

Choose **Save as a map**, select the destination mod and give the map a name and description. The map stores its ground, paths, fences, exhibits, objects and starting view. Live animals, guests and staff are created again during Play; they are not promised as saved map inhabitants.

Reopen the saved map before publishing it. Check the boundary, entrance, objects and custom resources. Enable its mod and the game's **custommaps** switch, then find it in Play's **Freeform** list and adopt or hire the live actors again.

## Useful controls

| In Test Zoo | Control |
|---|---|
| Place palette | P |
| Bulldoze | B |
| Undo | Ctrl+Z |
| Turn the selected placement | R |
| Change fence/path drag mode | Tab |
| Stop the current placement tool | Right-click |
| Route test | T |

Use these while the zoo view has focus. In a text field, keys edit text instead.
