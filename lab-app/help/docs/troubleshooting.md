# Find and fix common problems

## The species list is empty or shows an unexpected animal

Wait for **Engine running**, then reopen the creator. Confirm the kind and Behaves like preset before creating the animal. If a marine list shows an unrelated land fallback, cancel and let the catalogue reconnect.

## The drawing looks right but the game still shows old art

Save the drawing and wait for compilation. Confirm the correct slot and direction, and whether it is still linked to another drawing. Check that the intended mod is on and a competing replacement is off. Stop and start Play to reload loaded archives. A theme pack is a snapshot: rebuild it after changing a source mod.

## An animal will not place or is unhappy

Check the actual depth, enclosure, terrain, space, group and correct carer. Marine animals need a suitable tank; a swimming zoo animal may also need dry land. Read the Inspector's recommendations. Observe normal feeding and recovery over time rather than changing one value and stopping immediately.

## A dinosaur escapes

Check its inherited jumping and fence-breaking behavior, fence height and strength, and enclosure gaps. Test after hatching with suitable care. A successful egg placement does not prove containment. The Amberhorn tutorial's earlier low-glass escape is a known unresolved example.

## A building or staff member does nothing

Confirm its inherited role, registry kind, footprint and path access. Rotate the entrance toward the path, provide a real guest or task, and let time run. A new appearance does not create a new staff duty or guest role. Check work and service states as well as idle art.

## The saved map is missing animals

Map designs save the environment, not live inhabitants. Adopt animals and hire staff again in Play. Reopen the map to check ground, fences and objects, then use a game save for ordinary ongoing gameplay.

## The map is not in Freeform

Confirm **Save as a map** completed in the intended mod, enable that mod and **custommaps**, then restart Play. Check that you are running the engine version with mod maps.

## The repository picture is missing

Set an About picture, raise the version and upload through the current Lab. Wait for server approval. The fixed game build reads the repository cover before download; an older installed build needs the engine update. The installed picture and repository thumbnail are separate sizes. Legacy uploads can still have no thumbnail.

## Download says it cannot unpack an update

Unload the enabled archive first: switch it off, stop Play and restart the Lab, then retry. Keep your editable sources safe when testing updates. See [publishing and updating](help:publish).

## A panel vanished

Use **Layout** to reopen it or reset the tab. Help has its own article and contents navigation; opening it does not reset your dock layout.

## A check passes but behavior is still wrong

Local package rules, server scanning, creator Problems and species diagnostics check different things. Repeat the ordinary Play scenario and compare with the stock base. Note the map, mod version, actions and elapsed game time when reporting the bug.
