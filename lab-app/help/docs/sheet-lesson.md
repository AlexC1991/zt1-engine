# Indigo Springhare: a directional sprite sheet

Source: source-assets/indigo-springhare-sheet.png

Create a zoo animal based on Thomson’s Gazelle. Draw walk → Blank → Import external art. Select Grid, columns 4, rows 5, row directions N,NE,E,SE,S, height 42 and 120 ms per frame. Preview every view and all four walking frames.

Save compiles the game art. For this prototype, Link other poses reuses that art for the other adult states; wait for it to finish. Add its own food, habitat and group values in Needs and the Inspector. Pictures → Use an animation frame makes its icon, list picture and plaque.
