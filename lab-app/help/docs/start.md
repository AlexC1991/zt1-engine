# Start with the Lab

The Lab lets you make mods, build a test zoo, play the engine and investigate the original game. You can create a mod without writing engine code.

## Before you begin

Use your own installed copy of Zoo Tycoon. Wait for **Engine running** before opening species lists or placing things. **Ghidra connected** is needed for original-game code investigation, but you can read Help while it connects.

## Make your first mod

1. Open **Mods** and choose **New mod**. Give it a name and start with an empty studio.
2. Choose **Make something**. Start with **New animal**, **Build an item** or a map.
3. For an animal, choose Zoo, Marine or Dinosaur first, then a suitable **Behaves like** species. This provides its starting behavior and art slots.
4. Open a drawing. **Remake** copies existing art, **Stencil** gives you a faded guide to paint over, and **Blank** starts empty. **Import external art** accepts PNG images and OBJ meshes.
5. **Save** the drawing. Set the animal's **Needs**, **Pictures** and Inspector values, or the item's relevant properties. Wait for saves to finish.
6. Use **Test** to load the mod in the Test Zoo. Build its home yourself, add the appropriate staff, then run time and observe it.
7. Open **Play Game** and test ordinary purchasing, placement and gameplay. A picture in the editor alone does not prove it works in the game.
8. Set an **About** picture. **Publish → Check it** checks the local package. **Upload it** publishes only after the server's checks pass.

[Follow the three animal import lessons](help:animal-imports), [make objects](help:park-tutorial), or [build a habitat and theme pack](help:habitat-tutorial).

## Find your way around

| Tab | Use it for |
|---|---|
| Explore | Find a system, action or game value in plain words. |
| Original Game | Read and investigate your original zoo.exe. |
| Write Code | Edit and build the engine when you need to change its implementation. |
| Test Zoo | Arrange a controlled test, inspect animals and objects, and watch behavior. |
| Play Game | Try the ordinary player workflow in the engine or original game. |
| Mods | Create, edit, check and publish mods; inspect game files and Lab scripts. |
| Help | Search these guides and watch the recorded tutorials. Press F1 to return here. |

## Read, try, then come back

Use the **Open…** buttons above a guide to go to the relevant Lab tab. Help remembers your article, search and reading position while you switch tabs. The contents list jumps to a section. Search looks through article text as well as titles.

Guides and tutorial media are included in the app. The older overview is marked **Earlier interface**; the current studio lessons show the new Mods menu. Historical test screenshots may show older version numbers. Follow the current publishing and repository-picture guides for today's workflow.
