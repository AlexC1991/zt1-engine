Everything since v2026.10.20.

# What's new

- **Marine shows:** Build a show tank, connect it to the animals' home tanks, add grandstands and choose a trick schedule. Marine specialists run the shows automatically, and animals return home afterwards. Several home tanks can share one show tank.
- **Show admission:** Grandstands link to the show they face. Changing the show's ticket price updates all stands linked to it.
- **Saved games:** Load original Zoo Tycoon saves and save your current zoo as a shared `.zoo` file that both games can open. ZT1-Engine keeps its extra features in that same file; the original loads the parts it supports. Compatibility is still incomplete.
- **Animal behaviour:** Animals account for nearby animals when moving. Marine animals have individual plant, rock, depth, cleanliness and salinity needs. Animals such as walruses can use land and water.
- **Mod switches:** Downloaded mods start disabled. Enable them from the main menu or switch them during play in Game Options. A mod needed by the current map or its custom items stays enabled until it is no longer needed.
- **Lab mod editor:** Create new animals and objects, or customise existing ones. Edit their appearance, food, habitat needs and other properties. Buildings, staff, fences, gates, tank filters, plants, rocks, shelters, paths, terrain and dinosaur eggs are supported.
- **Artwork imports:** Import PNG images and sprite sheets. Import OBJ models and supplied poses to produce game artwork. Animation still needs frames or poses supplied by the creator.
- **Custom maps:** Build a map from an existing map or blank ground, set its entrance and boundary, and include it in a mod.
- **Theme packs:** Publish several mods together as one download, with a pack name, picture and description.
- **Lab Help:** A Help tab beside Mods includes searchable guides and tutorial videos for making, importing, testing and publishing mods. The guides work offline.
- **Game windows:** Keep information windows open side by side, drag and lock them, and remember their positions. These options can be switched off in Game Options.

# Bug fixes

- **Show animals:** Both eligible adult dolphins can take part. Animals recover from interrupted shows and return to their home tank. Show tricks no longer play randomly while animals swim in their normal exhibit.
- **Dolphin animations:** Airborne flips no longer disappear above the water.
- **Marine specialists:** Corrected platform height, ladder direction and automatic show assignments. Show tanks no longer receive ordinary feeding; animals are fed in their home tanks.
- **Show grandstands:** Corrected spectator height and seating positions.
- **Tank walls and gates:** Corrected animals drawing through walls, gates covering animals incorrectly, and objects drawing incorrectly near platforms and filters.
- **Tank platforms:** Platforms move to a clear location when a connected tank blocks access. The fence gate tool can also move them manually.
- **Tank placement:** Animal, plant, rock and toy previews use the correct floor or water height. Marine plants require a filled tank. Demolition highlights and selects the same item.
- **Tank filters:** Restored running animations, sounds, wear and maintenance visits. Different custom filters retain their own settings and artwork.
- **Dinosaur Response Team:** Corrected the base building's alignment when rotating the map, helicopter animations and dinosaur capture duties.
- **Shops and buildings:** Corrected rotated positions, animated parts and customer entrances. Custom buildings and staff use their own names and artwork.
- **Saved games:** Improved restoration of animals, guests, staff, research, finances, tank equipment and show programs. Failed loads preserve the open zoo and explain missing mod content. Fixed an unsafe first-load overlap with background research loading.
- **Original-game saves:** Corrected exported entrances, custom boundaries and tank contents that could stop the original from filling a tank. Converted saves no longer depend on the original file's old location.
- **Game Options:** Opening the menu pauses the zoo. Closing it keeps a manually paused game paused. The mod list now has clear arrow buttons and a page counter.
- **Construction:** Corrected the Tundra (Small) map boundary and held objects disappearing when rotated.
- **Camera performance:** Reduced work when drawing terrain, tanks and objects outside the camera view, and when processing show crowds.
- **Lab controls:** Corrected embedded game resizing and cases where closing a game file dialog left the Lab unclickable. Rebuilds retain the Test Zoo setup.
- **Portable download:** Included the mod-download client in the Game Build ZIP.
